# ⚡ Optivolt — EV Depot Demand Forecasting & Grid Capacity Planning

**Optivolt** is a Python and Streamlit application that uses machine learning to forecast electricity demand, assess grid-capacity risks and explore EV fleet-growth scenarios.

### 🌐 Live Application

**[Launch Optivolt](https://optivolt-project-4htmec97k5xzsa25mvtfeq.streamlit.app/)**

### 💻 Source Code

**[View the GitHub Repository](https://github.com/charlyclassy/Optivolt-Project)**

### Key Capabilities

- Short-term LSTM electricity-demand forecasting for up to 72 hours.
- Extended hybrid demand forecasting for up to 30 days.
- Grid-capacity monitoring and risk assessment.
- EV fleet-growth scenario analysis.
- Machine-learning model comparison and evaluation.
- Interactive dashboards, reporting and depot management.

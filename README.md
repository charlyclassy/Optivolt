Optivolt planning display formatting
==================================

Replace optivolt_lstm.py in your GitHub repository with this file.

The Planning Impact Assessment now displays the LSTM baseline peak, planning-based peak and remaining headroom with two decimal places. The peak labels in its capacity-utilisation comparison also show two decimals.

No forecast, planning, model, state, or slider calculations were modified.

In GitHub Desktop: commit the changed file, push origin, then refresh or reboot Streamlit. For a matching saved forecast whose Demand Prediction peak is 169.17 kW, the Planning baseline card should read 169.17 kW.
